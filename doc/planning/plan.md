# Dotfiles — Implementation Plan

The plan for this repo lives in the tsk ledger, on the `tsk/ledger` branch. Read it with tsk:

```bash
tsk ledger fetch
tsk ledger doc get index.md
```

`index.md` holds the current mission, the next steps and a table of every mission. Each
Delta from this file and its archive is now a mission briefing under `missions/operational/`.
